## 📱 客户端支持

<table>

<td align="center" width="150">
<img src="https://raw.githubusercontent.com/fieldw18/test/main/Icons/ProxyTools/Egern.png" width="64"><br>
<b>Egern</b><br>
<sub>规则</sub>
</td>
<td>

导入前缀（`match` 直接跟原始链接）：

```
https://egernapp.com/rules/new?type=rule_set&match={URL}&policy=DIRECT
```

导入后可在 Egern 内按需调整 `policy`，默认 `DIRECT`。

</td>
</tr>

</td>
<td>

导入前缀（链接需 URL 编码）：

```
规则   https://www.nsloon.com/openloon/import?rules=encode(URL)
图标集 https://www.nsloon.com/openloon/import?iconset=encode(URL)
```

</td>
